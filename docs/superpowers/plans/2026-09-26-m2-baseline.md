# M2 Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make experiments` compares dummy, logistic regression and LightGBM under the same stratified 5-fold CV on the train split and writes `reports/tables/experiments.csv`, with LightGBM near the lab's ROC-AUC (about 0.78).

**Architecture:** The experiment list lives in `configs/base.yaml` and is validated by `config.py` into `Experiment` records. `preprocess.py` builds a ColumnTransformer; `models.py` (written by the author) maps a model name to an estimator; `pipeline.py` joins them; `experiments.py` runs `cross_validate` for each experiment on one shared `StratifiedKFold`. `load_split` refuses a split made with different settings.

**Tech Stack:** Python 3.12, conda, pandas, scikit-learn, LightGBM, pytest.

**Spec:** `docs/superpowers/specs/2026-09-25-credit-default-risk-design.md`

## Global Constraints

- Every command runs from the repo root with `conda activate credit-risk` active.
- New dependencies go in `environment.yml`, then `conda env update -n credit-risk -f environment.yml --prune`.
- Ownership (option C, chosen by the author): the **author writes `get_model` in `models.py`** (Task 5). Claude writes everything else. Claude must not write the body of `get_model`; Task 4 creates a stub and stops for the author.
- All comparisons use the same stratified CV folds on train only (`StratifiedKFold(n_splits=cfg.cv_folds, shuffle=True, random_state=cfg.seed)`). The test split is not read in M2.
- No class weighting or resampling in M2 (that is M3). Models use library defaults apart from the settings named in Task 4.
- Metrics: ROC-AUC, PR-AUC (average precision), recall, precision, F1, fit time.
- `reports/tables/experiments.csv` is committed; `reports/smoke/` is gitignored.
- The author has added explanatory comments throughout `src/`. Edits must keep existing comments; change only the lines named.
- Docs and comments: no em dashes, plain factual tone.
- Work on branch `m2-baseline`; do not push or merge without asking the user.

```python
def _experiments(value: Any) -> tuple[Experiment, ...]:
    if not isinstance(value, list) or not value:
        raise ConfigError("'experiments' must be a non-empty list of {name, model, params}")
    experiments = []
    for i, item in enumerate(value):
        where = f"experiments[{i}]"
        if not isinstance(item, dict):
            raise ConfigError(f"'{where}' must be a mapping with keys name, model, params")
        _check_keys(where, item, {"name", "model"}, {"params"})
        params = item.get("params") or {}
        if not isinstance(params, dict):
            raise ConfigError(f"'{where}.params' must be a mapping, got {params!r}")
        experiments.append(Experiment(str(item["name"]), str(item["model"]), dict(params)))
    names = [e.name for e in experiments]
    duplicates = sorted({n for n in names if names.count(n) > 1})
    if duplicates:
        raise ConfigError(f"Duplicate experiment name(s): {duplicates}")
    return tuple(experiments)
```

`src/credit_risk/preprocess.py`:
```python
"""Column transformations applied before any model.

- NUMERIC (credit limit, age, bill and payment amounts): standardized, so linear
  models see them on one scale. Tree models are unaffected by scaling.
- CATEGORICAL (sex, education, marriage): one-hot encoded. The codes are labels,
  not quantities, so "EDUCATION = 3" should not mean "three times EDUCATION = 1".
  A level not seen during fitting is encoded as all zeros instead of raising.
- ORDINAL (PAY_1 to PAY_6): kept as numbers, since -2 to 8 runs roughly from least
  to most risky.
- ID and any other column are dropped.
"""

from __future__ import annotations

from sklearn.compose import ColumnTransformer, make_column_transformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler

from credit_risk.data import BILL_AMTS, PAY_AMTS, PAY_STATUS

NUMERIC = ["LIMIT_BAL", "AGE", *BILL_AMTS, *PAY_AMTS]
CATEGORICAL = ["SEX", "EDUCATION", "MARRIAGE"]
ORDINAL = PAY_STATUS


def build_preprocessor() -> ColumnTransformer:
    """A fresh, unfitted ColumnTransformer that outputs a pandas DataFrame."""
    preprocessor = make_column_transformer(
        (StandardScaler(), NUMERIC),
        (
            OneHotEncoder(drop="if_binary", handle_unknown="ignore", sparse_output=False),
            CATEGORICAL,
        ),
        ("passthrough", ORDINAL),
        remainder="drop",
        verbose_feature_names_out=False,
    )
    return preprocessor.set_output(transform="pandas")
```

```python
"""Compare model setups with cross-validation on the training split.

Every experiment uses the same folds (one StratifiedKFold with a fixed seed), so
differences in the table come from the setups, not from which rows landed in
which fold.
"""

from __future__ import annotations

from pathlib import Path

import pandas as pd
from sklearn.metrics import f1_score, make_scorer, precision_score
from sklearn.model_selection import StratifiedKFold, cross_validate

from credit_risk.config import Config, ConfigError
from credit_risk.data import TARGET, load_split
from credit_risk.pipeline import build_pipeline

# Metric name in the table -> scikit-learn scorer. zero_division=0 reports precision
# and F1 as 0 (instead of warning) when a model predicts no defaulters at all.
SCORERS = {
    "roc_auc": "roc_auc",
    "pr_auc": "average_precision",
    "recall": "recall",
    "precision": make_scorer(precision_score, zero_division=0),
    "f1": make_scorer(f1_score, zero_division=0),
}
METRICS = tuple(SCORERS)


def run_experiments(cfg: Config, train: pd.DataFrame | None = None) -> pd.DataFrame:
    """Cross-validate every experiment in cfg and return one summary row per experiment."""
    if not cfg.experiments:
        raise ConfigError("No experiments defined; add an 'experiments' list to the config.")
    if train is None:
        train = load_split("train", cfg)
    X, y = train.drop(columns=TARGET), train[TARGET]

    # Build every pipeline first, so a typo in a model name fails before any CV runs.
    pipelines = {e.name: (e, build_pipeline(e, cfg.seed)) for e in cfg.experiments}
    folds = StratifiedKFold(n_splits=cfg.cv_folds, shuffle=True, random_state=cfg.seed)

    rows = []
    for name, (experiment, pipe) in pipelines.items():
        scores = cross_validate(pipe, X, y, cv=folds, scoring=SCORERS, return_train_score=True)
        row = {"experiment": name, "model": experiment.model}
        for metric in METRICS:
            row[f"{metric}_mean"] = scores[f"test_{metric}"].mean()
            row[f"{metric}_std"] = scores[f"test_{metric}"].std()
        row["train_roc_auc_mean"] = scores["train_roc_auc"].mean()
        row["fit_time_mean"] = scores["fit_time"].mean()
        rows.append(row)
    return pd.DataFrame(rows)


def experiments_table_path(cfg: Config) -> Path:
    return cfg.paths.reports_dir / "tables" / "experiments.csv"


def save_experiments(table: pd.DataFrame, cfg: Config) -> Path:
    path = experiments_table_path(cfg)
    path.parent.mkdir(parents=True, exist_ok=True)
    table.round(4).to_csv(path, index=False)
    return path
```
