# M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the `credit-default-risk` repo so `make setup lint test smoke` passes, with a working `data` stage (raw CSV hash check) and stub stages for everything later.

**Architecture:** A `src/`-layout Python package (`credit_risk`) installed in editable mode by `uv sync`. A typed, validated YAML config (`config.py`) supplies all paths and settings; paths resolve against the project root so notebooks and tests can load the same config. A `credit-risk` console script (`cli.py`) exposes one subcommand per pipeline stage, and the Makefile calls it.

**Tech Stack:** Python 3.12, uv, hatchling, pandas (declared for M1), PyYAML, pytest, ruff, pre-commit, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-25-credit-default-risk-design.md`

## Global Constraints

- Python `>=3.12,<3.13`; `uv.lock` is committed; CI installs with `uv sync --locked`.
- Package name `credit_risk` in `src/credit_risk/`; console script `credit-risk`.
- Raw data at `data/raw/UCI_Credit_Card.csv`, committed, sha256 `a0f0ab49d6326671d6cd83be5c88dcf18007025fe9a53ecd699119c871176ca1`, LF line endings.
- `data/processed/` and `artifacts/` are gitignored.
- Seed `573`, test size `0.2`, CV folds `5` in `configs/base.yaml`; `configs/smoke.yaml` uses about 1,000 rows and 2 folds.
- Only add dependencies a task uses. Later libraries (scikit-learn, lightgbm, shap, and so on) are added in the milestone that needs them.
- Writing style for README and docs: no em dashes, plain factual tone, no hype.
- Work on branch `m0-scaffold`; do not push or create a GitHub remote without asking the user.

## Review Focus

- Loading a config from another working directory (e.g. a notebook in `notebooks/`): paths should resolve against the project root, not the cwd. Pinned in Task 2.
- A typo in a config key (e.g. `cv_fold`): should fail at load with a message naming the valid keys, not later with a `KeyError`. Pinned in Task 2.
- Git converting line endings on checkout (Windows `autocrlf`): would change the CSV bytes and break the hash check. `.gitattributes` marks raw CSVs `-text`. Pinned in Task 3.
- An `extends` loop between config files: should raise a clear `ConfigError`, not `RecursionError`. Pinned in Task 2.
- A failing stage run from `make`: should print a one-line `error:` message and exit non-zero so `make` stops, not print a traceback or exit 0. Pinned in Task 4.

```python
"""Load and validate project configuration from YAML.

Paths in a config file are relative to the project root (the nearest folder
above the config file that holds pyproject.toml), so the same config works
from the Makefile, tests, and notebooks.
"""

from __future__ import annotations

import re
from dataclasses import dataclass
from pathlib import Path
from typing import Any

import yaml


class ConfigError(ValueError):
    """Raised when a config file is missing, malformed, or has invalid values."""


@dataclass(frozen=True)
class Paths:
    raw: Path
    processed_dir: Path
    reports_dir: Path
    artifacts_dir: Path


@dataclass(frozen=True)
class Costs:
    false_negative: float
    false_positive: float


@dataclass(frozen=True)
class Config:
    paths: Paths
    raw_sha256: str
    seed: int
    test_size: float
    cv_folds: int
    costs: Costs
    sample_rows: int | None = None


_TOP_REQUIRED = {"paths", "raw_sha256", "seed", "test_size", "cv_folds", "costs"}
_TOP_OPTIONAL = {"sample_rows"}
_PATH_KEYS = {"raw", "processed_dir", "reports_dir", "artifacts_dir"}
_COST_KEYS = {"false_negative", "false_positive"}


def find_project_root(start: Path) -> Path:
    """Return the nearest directory at or above `start` containing pyproject.toml."""
    start = start.resolve()
    for directory in (start, *start.parents):
        if (directory / "pyproject.toml").is_file():
            return directory
    raise ConfigError(f"No pyproject.toml found at or above {start}; cannot locate project root.")


def load_config(path: str | Path) -> Config:
    """Read a YAML config (following `extends`), validate it, and return a Config."""
    path = Path(path).resolve()
    data = _read_yaml(path, frozenset())
    _check_keys("config", data, _TOP_REQUIRED, _TOP_OPTIONAL)
    root = find_project_root(path.parent)

    paths = _section(data, "paths", _PATH_KEYS)
    costs = _section(data, "costs", _COST_KEYS)
    sample_rows = data.get("sample_rows")

    return Config(
        paths=Paths(**{key: root / str(value) for key, value in paths.items()}),
        raw_sha256=_sha256(data["raw_sha256"]),
        seed=_int("seed", data["seed"], minimum=0),
        test_size=_fraction("test_size", data["test_size"]),
        cv_folds=_int("cv_folds", data["cv_folds"], minimum=2),
        costs=Costs(
            false_negative=_positive("costs.false_negative", costs["false_negative"]),
            false_positive=_positive("costs.false_positive", costs["false_positive"]),
        ),
        sample_rows=None if sample_rows is None else _int("sample_rows", sample_rows, minimum=1),
    )


def _read_yaml(path: Path, seen: frozenset[Path]) -> dict[str, Any]:
    path = path.resolve()
    if path in seen:
        raise ConfigError(f"Config 'extends' cycle involving {path}")
    if not path.is_file():
        raise ConfigError(f"Config file not found: {path}")
    data = yaml.safe_load(path.read_text())
    if not isinstance(data, dict):
        raise ConfigError(f"Config file {path} must contain a YAML mapping of keys to values")
    parent = data.pop("extends", None)
    if parent is None:
        return data
    base = _read_yaml(path.parent / str(parent), seen | {path})
    return _deep_merge(base, data)


def _deep_merge(base: dict[str, Any], override: dict[str, Any]) -> dict[str, Any]:
    merged = dict(base)
    for key, value in override.items():
        if isinstance(value, dict) and isinstance(merged.get(key), dict):
            merged[key] = _deep_merge(merged[key], value)
        else:
            merged[key] = value
    return merged


def _check_keys(
    section: str,
    data: dict[str, Any],
    required: set[str],
    optional: set[str] | frozenset[str] = frozenset(),
) -> None:
    valid = required | optional
    unknown = set(data) - valid
    if unknown:
        raise ConfigError(
            f"Unknown key(s) in {section}: {sorted(unknown)}. Valid keys: {sorted(valid)}"
        )
    missing = required - set(data)
    if missing:
        raise ConfigError(f"Missing required key(s) in {section}: {sorted(missing)}")


def _section(data: dict[str, Any], name: str, keys: set[str]) -> dict[str, Any]:
    section = data[name]
    if not isinstance(section, dict):
        raise ConfigError(f"'{name}' must be a mapping with keys {sorted(keys)}")
    _check_keys(name, section, keys)
    return section


def _is_number(value: Any) -> bool:
    return isinstance(value, int | float) and not isinstance(value, bool)


def _int(key: str, value: Any, minimum: int) -> int:
    if isinstance(value, bool) or not isinstance(value, int) or value < minimum:
        raise ConfigError(f"'{key}' must be an integer >= {minimum}, got {value!r}")
    return value


def _fraction(key: str, value: Any) -> float:
    if not _is_number(value) or not 0 < value < 1:
        raise ConfigError(f"'{key}' must be a number between 0 and 1 (exclusive), got {value!r}")
    return float(value)


def _positive(key: str, value: Any) -> float:
    if not _is_number(value) or value <= 0:
        raise ConfigError(f"'{key}' must be a number > 0, got {value!r}")
    return float(value)


def _sha256(value: Any) -> str:
    text = str(value)
    if not re.fullmatch(r"[0-9a-f]{64}", text):
        raise ConfigError(f"'raw_sha256' must be 64 lowercase hex characters, got {text!r}")
    return text
```

```python
"""Raw data access and validation."""

from __future__ import annotations

import hashlib
from pathlib import Path

from credit_risk.config import Config


class DataFileError(RuntimeError):
    """Raised when a data file is missing or does not match what the pipeline expects."""


def sha256_of(path: Path) -> str:
    """Return the hex sha256 of a file, read in 1 MB chunks."""
    digest = hashlib.sha256()
    with path.open("rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            digest.update(chunk)
    return digest.hexdigest()


def verify_raw(cfg: Config) -> None:
    """Check that the raw CSV exists and matches the expected sha256."""
    path = cfg.paths.raw
    if not path.is_file():
        raise DataFileError(
            f"Raw data not found at {path}. It is committed to the repo; "
            f"restore it with `git checkout -- {path.name}` from its folder."
        )
    actual = sha256_of(path)
    if actual != cfg.raw_sha256:
        raise DataFileError(
            f"Raw data at {path} has changed.\n"
            f"  expected sha256: {cfg.raw_sha256}\n"
            f"  actual sha256:   {actual}\n"
            "Restore the committed file with `git checkout -- data/raw/`."
        )
```

```python
"""Command-line entry point: one subcommand per pipeline stage.

Usage: credit-risk [--config PATH] {data,split,experiments,train,evaluate,explain}
"""

from __future__ import annotations

import argparse
import sys

from credit_risk.config import Config, ConfigError, load_config
from credit_risk.data import DataFileError, verify_raw

DEFAULT_CONFIG = "configs/base.yaml"

# Stages not built yet, and the milestone that builds each one.
_PENDING = {
    "split": "M1",
    "experiments": "M2",
    "train": "M5",
    "evaluate": "M6",
    "explain": "M6",
}


def _run_data(cfg: Config) -> None:
    verify_raw(cfg)
    print(f"OK: {cfg.paths.raw} matches the expected sha256.")


_STAGES = {"data": _run_data}


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="credit-risk", description="Run one stage of the credit default pipeline."
    )
    parser.add_argument(
        "--config", default=DEFAULT_CONFIG, help=f"YAML config file (default: {DEFAULT_CONFIG})"
    )
    stages = parser.add_subparsers(dest="stage", required=True, metavar="STAGE")
    stages.add_parser("data", help="check the raw CSV against its expected sha256")
    for name, milestone in _PENDING.items():
        stages.add_parser(name, help=f"not implemented yet (milestone {milestone})")
    return parser


def main(argv: list[str] | None = None) -> int:
    args = build_parser().parse_args(argv)
    try:
        cfg = load_config(args.config)
        if args.stage in _STAGES:
            _STAGES[args.stage](cfg)
        else:
            print(
                f"Stage '{args.stage}' is not implemented yet "
                f"(planned for milestone {_PENDING[args.stage]})."
            )
    except (ConfigError, DataFileError) as exc:
        print(f"error: {exc}", file=sys.stderr)
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# credit-default-risk

Predicting whether a credit card client will miss next month's payment, built as a
modular, reproducible ML pipeline.

> Status: work in progress. The project scaffold is in place; modelling stages are
> being added milestone by milestone (see the [design spec](docs/superpowers/specs/2026-09-25-credit-default-risk-design.md)).

## The problem

The [Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)
dataset has 30,000 clients from Taiwan (2005) with credit limit, demographics, six months
of repayment status, bill amounts, and payment amounts. About 22% of clients default.
The goal is to rank clients by default risk and choose a decision threshold based on the
cost of each type of error, rather than the default 0.5 cutoff.

## Quickstart

Requires [uv](https://docs.astral.sh/uv/) and `make`.

```bash
make setup   # install dependencies and git hooks
make test    # run the test suite
make all     # run the pipeline end to end
```

Each stage can also be run on its own (`make data`, `make split`, ...). Use a different
config with `make all CONFIG=configs/smoke.yaml`.

## Project layout

```
configs/          settings for every stage (paths, seed, CV folds, error costs)
data/raw/         the original CSV (committed; checked by sha256)
src/credit_risk/  the package: one module per pipeline responsibility
tests/            pytest suite, including a small end-to-end smoke run
notebooks/        exploration and write-up; imports from the package
docs/             design spec, plans, and a learning log
```

## Acknowledgements

This project grew out of a group lab for DSCI 573 (Feature and Model Selection) in the
UBC Master of Data Science program, completed with Vy and Christine. The pipeline,
feature engineering, experiments, and write-up in this repository are a separate,
individual rebuild.

Data: Yeh, I. C., and Lien, C. H. (2009). The comparisons of data mining techniques for
the predictive accuracy of probability of default of credit card clients. *Expert
Systems with Applications*, 36(2), 2473-2480. Distributed via the UCI Machine Learning
Repository.
````
