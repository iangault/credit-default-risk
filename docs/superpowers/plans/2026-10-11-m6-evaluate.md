# M6 Evaluate and Explain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make evaluate` scores the saved model on the test set (metrics, comparisons, counts, calibration plot) and `make explain` produces SHAP figures for the test set and two typical clients, without changing the model.

**Architecture:** `make train` gains a `model.json` record of the settings it used; `load_model` refuses a model whose record does not match the config. New `evaluate.py` computes test metrics at the tuned threshold and at 0.5, two baselines, and the train cross-validation estimate read from the committed tables, plus an Altair calibration plot. New `explain.py` reaches the fitted pipeline inside the calibration wrapper, runs `shap.TreeExplainer` on its model step, shows original (unscaled) values, picks two clients by a fixed rule, and draws a beeswarm and two waterfalls with matplotlib. Two CLI stages and Make targets run them.

**Tech Stack:** Python 3.12, conda, pandas, numpy, scikit-learn 1.9, LightGBM, joblib, Altair 6 + vl-convert, **new:** `shap` (>=0.50) and `matplotlib-base` (>=3.8), pytest.

**Spec:** `docs/superpowers/specs/2026-09-25-credit-default-risk-design.md` (Success criteria: test set rule; Pipeline stages: evaluate, explain, stale model check; Modules: `evaluate.py`, `explain.py`; M6 row).

## Global Constraints

- Every command runs from the repo root with `conda run -n credit-risk` (or the env activated).
- Ownership: on 2026-10-11 the author chose to have Claude write all of M6, pausing after each task for review.
- **Annotations:** new and changed code carries explanatory comments in the style already in `src/`. `explain.py`'s docstring explains what SHAP values are, their units, and how to read a beeswarm and a waterfall.
- **Test set rule (spec, changed in M6):** "The test set is read only by `evaluate` and `explain`. Neither changes the model, and no setting is changed after seeing their output." No task reads `test.parquet` before Task 6. Tests use samples of the cleaned raw data, not the test split.
- Rows reported by `make evaluate`, in order: `model at tuned threshold`, `model at 0.5`, `flag nobody`, `flag everyone`, `train CV estimate`. Columns: `setup, threshold, roc_auc, pr_auc, recall, precision, expected_cost, flagged, caught, missed, false_alarms`.

- SHAP: `shap.TreeExplainer` on the model step of the fitted pipeline, applied to the pipeline's transformed columns; values in the model's score units before calibration (log-odds for LightGBM and XGBoost, probability for random forest); displayed values are the original, unscaled ones.     """The config settings that determine the saved model.

```python
"""Score the saved model on the test set (M6).

The test set (20% of clients, split off in M1) has not been used for any choice: model,
features, class weights, calibration, threshold and costs were all chosen on train. So
the numbers here estimate how the model does on clients it has never seen. Per the spec,
no setting is changed after seeing them; a disappointing result is reported, not tuned.

The table has five rows, so each number can be judged against something:
- model at tuned threshold: the saved model as it would be used (cutoff from M5).
- model at 0.5: the same scores with the default cutoff, to show what M5's threshold did.
- flag nobody / flag everyone: the cost of not using a model at all.
- train CV estimate: what cross-validation on train predicted, read from the committed
  experiments.csv and decision.csv. Close agreement means the estimates were trustworthy.

ROC-AUC and PR-AUC measure ranking, so they do not depend on the cutoff; the two model
rows share them. Counts: flagged (predicted defaulters), caught and missed (defaulters
flagged or not), false_alarms (flagged clients who paid).
"""

from __future__ import annotations

from collections.abc import Sequence

import numpy as np
import pandas as pd
from sklearn.metrics import (
    average_precision_score,
    precision_score,
    recall_score,
    roc_auc_score,
)
from sklearn.model_selection import TunedThresholdClassifierCV

from credit_risk.config import Config, Costs
from credit_risk.data import TARGET
from credit_risk.decision import decision_table_path, expected_cost
from credit_risk.experiments import experiments_table_path

COLUMNS = [
    "setup",
    "threshold",
    "roc_auc",
    "pr_auc",
    "recall",
    "precision",
    "expected_cost",
    "flagged",
    "caught",
    "missed",
    "false_alarms",
]


def _outcome_metrics(y: np.ndarray, flagged: np.ndarray, costs: Costs) -> dict:
    """Recall, precision, cost and counts for a given set of flagged clients."""
    return {
        "recall": recall_score(y, flagged, zero_division=0),
        # zero_division=0: report 0 (not a warning) when nobody is flagged.
        "precision": precision_score(y, flagged, zero_division=0),
        "expected_cost": expected_cost(y, flagged.astype(int), costs),
        "flagged": int(flagged.sum()),
        "caught": int((flagged & (y == 1)).sum()),
        "missed": int((~flagged & (y == 1)).sum()),
        "false_alarms": int((flagged & (y == 0)).sum()),
    }


def decision_metrics(
    y: Sequence[int], proba: Sequence[float], threshold: float, costs: Costs
) -> dict:
    """Metrics when clients with probability >= threshold are flagged.

    `>=` matches the saved model's predict (TunedThresholdClassifierCV).
    """
    y, proba = np.asarray(y), np.asarray(proba)
    return {"threshold": threshold, **_outcome_metrics(y, proba >= threshold, costs)}


def train_estimate(cfg: Config) -> dict:
    """The train cross-validation numbers for the chosen setup, from the committed tables.

    ROC-AUC and PR-AUC come from experiments.csv (the uncalibrated model; sigmoid
    calibration keeps the order of clients, so ranking metrics match). Threshold and cost
    come from decision.csv. A value not found (no table yet, or costs changed without
    rerunning make decide) is NaN, so the row shows blanks instead of failing.
    """
    estimate = dict.fromkeys(["threshold", "roc_auc", "pr_auc", "expected_cost"], np.nan)
    final, fn_cost = cfg.final, cfg.costs.false_negative
    if experiments_table_path(cfg).is_file():
        experiments = pd.read_csv(experiments_table_path(cfg))
        match = experiments[experiments["experiment"] == final.experiment]
        if len(match) == 1:
            estimate["roc_auc"] = float(match["roc_auc_mean"].iloc[0])
            estimate["pr_auc"] = float(match["pr_auc_mean"].iloc[0])
    if decision_table_path(cfg).is_file():
        decision = pd.read_csv(decision_table_path(cfg))
        match = decision[
            (decision["experiment"] == final.experiment)
            & (decision["calibration"] == final.calibration)
            & np.isclose(decision["false_negative_cost"], fn_cost)
        ]
        if len(match) == 1:
            estimate["threshold"] = float(match["threshold"].iloc[0])
            estimate["expected_cost"] = float(match["expected_cost"].iloc[0])
    return estimate


def evaluate(
    model: TunedThresholdClassifierCV, test: pd.DataFrame, cfg: Config
) -> tuple[pd.DataFrame, np.ndarray]:
    """The five-row comparison table on `test`, and the calibrated test probabilities."""
    X, y = test.drop(columns=TARGET), test[TARGET].to_numpy()
    proba = model.predict_proba(X)[:, 1]  # calibrated probability of default
    ranking = {"roc_auc": roc_auc_score(y, proba), "pr_auc": average_precision_score(y, proba)}
    nobody, everyone = np.zeros(len(y), dtype=bool), np.ones(len(y), dtype=bool)
    rows = [
        {"setup": "model at tuned threshold", **ranking,
         **decision_metrics(y, proba, model.best_threshold_, cfg.costs)},
        {"setup": "model at 0.5", **ranking, **decision_metrics(y, proba, 0.5, cfg.costs)},
        {"setup": "flag nobody", **_outcome_metrics(y, nobody, cfg.costs)},
        {"setup": "flag everyone", **_outcome_metrics(y, everyone, cfg.costs)},
        {"setup": "train CV estimate", **train_estimate(cfg)},
    ]
    return pd.DataFrame(rows, columns=COLUMNS), proba
```

```python
def plot_calibration(y: Sequence[int], proba: Sequence[float]) -> alt.LayerChart:
    """Predicted probability against the actual default rate, in 10 equal-size groups.

    Clients are sorted by predicted probability and cut into 10 groups of about the same
    size ("quantile"). Each point is one group: its average prediction (x) and the share
    of its clients who defaulted (y). Points on the diagonal mean the probabilities are
    honest: clients given about 30% default about 30% of the time.
    """
    observed, predicted = calibration_curve(y, proba, n_bins=10, strategy="quantile")
    groups = pd.DataFrame({"predicted": predicted, "observed": observed})
    top = float(max(predicted.max(), observed.max()))
    diagonal = pd.DataFrame({"predicted": [0.0, top], "observed": [0.0, top]})
    points = (
        alt.Chart(groups)
        .mark_line(point=True)
        .encode(
            x=alt.X("predicted:Q", title="Average predicted probability of default"),
            y=alt.Y("observed:Q", title="Actual default rate"),
        )
    )
    ideal = alt.Chart(diagonal).mark_line(color="gray", strokeDash=[4, 4]).encode(
        x="predicted:Q", y="observed:Q"
    )
    return alt.layer(points, ideal).properties(
        title=alt.TitleParams(
            "Calibration on the test set",
            subtitle="10 equal-size groups of clients; dashed line: perfect calibration",
        ),
        width=400,
        height=400,
    )
```

```python
"""Explain the saved model's predictions with SHAP (M6).

SHAP values split one prediction into a contribution from each column. For a client,
    model score = base value + sum of the client's SHAP values,
where the base value is the model's average score. A positive SHAP value means that
column pushed this client's score toward default; negative, away from it. The values come
from game theory (Shapley values): each column gets its average contribution over every
order in which columns could be added. For tree models shap.TreeExplainer computes them
exactly and fast.

Units: SHAP explains the model step inside the saved pipeline, so values are in that
model's score before calibration: log-odds for LightGBM and XGBoost (a value of +0.7
multiplies the odds of default by about 2), probability for random forest. Sigmoid
calibration keeps the order of clients, so "pushes risk up" means the same either way.

Plots (reports/figures/):
- shap_summary.png (beeswarm): one row per column, most important at the top; one dot
  per test client, placed left or right by its SHAP value, colored by the column's value
  (red high, blue low). Example reading: red dots far right on PAY_1 mean recent late
  payment pushes risk up a lot.
- shap_client_flagged.png, shap_client_missed.png (waterfalls): one client each, from the
  base value at the bottom to their score at the top, one bar per column.

The model sees transformed columns (scaled amounts, one-hot categories). The plots show
each column's original value where the column keeps its name (LIMIT_BAL = 50000, not
-0.9); one-hot columns such as SEX_2 show 0 or 1.
"""

from __future__ import annotations

from collections.abc import Sequence

import numpy as np
import pandas as pd
import shap
from imblearn.pipeline import Pipeline
from sklearn.model_selection import TunedThresholdClassifierCV

from credit_risk.config import Config, ConfigError

# Models shap.TreeExplainer can explain. The final model must be one of these.
TREE_MODELS = ("lgbm", "xgboost", "forest")


def check_tree_model(cfg: Config) -> None:
    """Stop early if the final setup's model is not a tree model."""
    if cfg.final is None:
        raise ConfigError("No 'final' section in the config; set it and run `make train`.")
    experiment = {e.name: e for e in cfg.experiments}[cfg.final.experiment]
    if experiment.model not in TREE_MODELS:
        raise ConfigError(
            f"make explain supports tree models ({', '.join(TREE_MODELS)}); the final "
            f"setup '{experiment.name}' uses '{experiment.model}'."
        )


def inner_pipeline(model: TunedThresholdClassifierCV) -> Pipeline:
    """The fitted pipeline inside the saved model (see decision.py's module docstring).

    model.estimator_ is the CalibratedClassifierCV refit on all of train. With
    ensemble=False it holds one (pipeline, calibrator) pair in calibrated_classifiers_,
    and .estimator is that pipeline, fitted on all of train.
    """
    return model.estimator_.calibrated_classifiers_[0].estimator


def shap_explanation(model: TunedThresholdClassifierCV, X: pd.DataFrame) -> shap.Explanation:
    """SHAP values for each row of X, with original (unscaled) values for display."""
    pipe = inner_pipeline(model)
    # pipe[:-1] is every step except the model: features, scaling, encoding. Its output
    # is what the model was trained on, so SHAP must explain the model on that.
    transformed = pipe[:-1].transform(X)
    explanation = shap.TreeExplainer(pipe.named_steps["model"])(transformed)
    values, base = explanation.values, explanation.base_values
    if values.ndim == 3:
        # Random forest returns one set per class (no default, default); keep default.
        values, base = values[:, :, 1], base[:, 1]
    display = transformed.copy()
    kept = [column for column in display.columns if column in X.columns]
    display[kept] = X[kept].to_numpy()  # same rows in the same order
    return shap.Explanation(
        values=values,
        base_values=base,
        data=display.to_numpy(),
        feature_names=list(display.columns),
    )


def pick_clients(
    y: Sequence[int], proba: Sequence[float], threshold: float
) -> dict[str, int]:
    """Row numbers of a typical correctly flagged defaulter and a typical missed one.

    A fixed rule, chosen before seeing the test set, so the examples are not hand-picked:
    in each group, the client whose probability is nearest the group's median. A group
    with no clients (possible on a small test set) is left out.
    """
    y, proba = np.asarray(y), np.asarray(proba)
    flagged = proba >= threshold
    groups = {"flagged": (y == 1) & flagged, "missed": (y == 1) & ~flagged}
    picks = {}
    for name, in_group in groups.items():
        rows = np.flatnonzero(in_group)
        if len(rows) == 0:
            continue
        distance = np.abs(proba[rows] - np.median(proba[rows]))
        picks[name] = int(rows[np.argmin(distance)])  # ties: the first such row
    return picks
```

```python
def importance_table(explanation: shap.Explanation) -> pd.DataFrame:
    """Mean absolute SHAP value per column: how much it moves scores on average."""
    table = pd.DataFrame(
        {
            "feature": explanation.feature_names,
            "mean_abs_shap": np.abs(explanation.values).mean(axis=0),
        }
    )
    return table.sort_values("mean_abs_shap", ascending=False, ignore_index=True)


def explain_paths(cfg: Config) -> dict[str, Path]:
    """Where make explain writes each output."""
    figures, tables = cfg.paths.reports_dir / "figures", cfg.paths.reports_dir / "tables"
    return {
        "summary": figures / "shap_summary.png",
        "flagged": figures / "shap_client_flagged.png",
        "missed": figures / "shap_client_missed.png",
        "importance": tables / "shap_importance.csv",
    }


def _save_figure(path: Path, title: str) -> None:
    plt.title(title, fontsize=10)
    plt.savefig(path, dpi=150, bbox_inches="tight")
    plt.close("all")  # start the next plot on a fresh figure


def save_explanations(
    model: TunedThresholdClassifierCV, X: pd.DataFrame, y: pd.Series, cfg: Config
) -> tuple[list[Path], dict[str, int]]:
    """Write the beeswarm, the two client waterfalls and the importance table.

    Returns the paths written and the picked row numbers (a group with no clients has no
    waterfall).
    """
    paths = explain_paths(cfg)
    for path in paths.values():
        path.parent.mkdir(parents=True, exist_ok=True)
    explanation = shap_explanation(model, X)
    written = []

    shap.plots.beeswarm(explanation, max_display=15, show=False)
    _save_figure(paths["summary"], "SHAP values on the test set (model score before calibration)")
    written.append(paths["summary"])

    proba = model.predict_proba(X)[:, 1]
    picks = pick_clients(y, proba, model.best_threshold_)
    labels = {"flagged": "correctly flagged defaulter", "missed": "missed defaulter"}
    for name, row in picks.items():
        shap.plots.waterfall(explanation[row], max_display=12, show=False)
        _save_figure(
            paths[name],
            f"Client {X['ID'].iloc[row]}: {labels[name]} "
            f"(calibrated probability {proba[row]:.2f}, threshold {model.best_threshold_:.2f})",
        )
        written.append(paths[name])

    importance_table(explanation).round(4).to_csv(paths["importance"], index=False)
    written.append(paths["importance"])
    return written, picks
```
