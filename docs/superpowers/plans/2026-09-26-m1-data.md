# M1 Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make split` cleans the raw CSV using the eight approved decisions and writes a stratified train/test split, which a notebook can load with `load_split("train")` from any folder in the project. It ends with an EDA notebook scaffold for the author.

**Architecture:** `data.py` grows from a hash check into the data module: `load_raw` (verify, then read), `clean` (pure function: rename, merge undocumented codes, validate), `split` (optional stratified sample, then stratified split), `save_splits` and `load_split`. `cli.py` wires `split` as a real stage. The default config is found from the project root, so notebooks and subfolders work without paths.

**Tech Stack:** Python 3.12, conda (conda-forge), pandas, scikit-learn (`train_test_split`), pyarrow (Parquet), pytest, JupyterLab, Altair.

**Spec:** `docs/superpowers/specs/2026-09-25-credit-default-risk-design.md`

## Global Constraints

- Every command runs from the repo root with `conda activate credit-risk` active.
- New dependencies go in `environment.yml`, then `conda env update -n credit-risk -f environment.yml --prune`. `pyproject.toml` keeps `dependencies = []`.
- Split: stratified on `default`, `test_size` 0.2, `seed` 573, from `configs/base.yaml`. Smoke config: `sample_rows: 1000`, `cv_folds: 2`.
- The test set is read by one stage only (`evaluate`, M6). The EDA notebook uses train only.
- `data/processed/` and `artifacts/` stay gitignored.
- Cleaning decisions approved by the author (implement exactly these):
  1. EDUCATION codes 0, 5, 6 become 4 ("other/unknown").
  2. MARRIAGE code 0 becomes 3 ("other").
  3. PAY_x values (-2 to 8) are kept as-is.
  4. `PAY_0` is renamed `PAY_1`.
  5. Negative BILL_AMT values are kept.
  6. The 35 rows identical apart from ID are kept.
  7. Target `default.payment.next.month` is renamed `default`.
  8. `ID` is kept through the split (dropped in M2 preprocessing).
- Docs and comments: no em dashes, plain factual tone.
- Work on branch `m1-data`; do not push or merge without asking the user.

def load_raw(cfg: Config) -> pd.DataFrame:
    """Check the raw CSV's hash, then read it."""
    verify_raw(cfg)
    return pd.read_csv(cfg.paths.raw)


def clean(df: pd.DataFrame) -> pd.DataFrame:
    """Apply the cleaning decisions in the module docstring. Returns a new DataFrame."""
    missing = [col for col in RAW_COLUMNS if col not in df.columns]
    if missing:
        raise DataFileError(f"Raw data is missing column(s): {missing}")

    out = df[RAW_COLUMNS].copy()
    out = out.rename(columns={"PAY_0": "PAY_1", RAW_TARGET: TARGET})
    out["EDUCATION"] = out["EDUCATION"].replace({0: _EDUCATION_OTHER, 5: _EDUCATION_OTHER, 6: _EDUCATION_OTHER})
    out["MARRIAGE"] = out["MARRIAGE"].replace({0: _MARRIAGE_OTHER})

    for col, allowed in _ALLOWED_VALUES.items():
        unexpected = sorted({int(v) for v in out[col].unique()} - allowed)
        if unexpected:
            raise DataFileError(
                f"Column {col} has unexpected value(s) {unexpected}; expected {sorted(allowed)}"
            )
    return out
```

def split(df: pd.DataFrame, cfg: Config) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Stratified train/test split, after an optional stratified sample of cfg.sample_rows."""
    if cfg.sample_rows is not None and cfg.sample_rows < len(df):
        df, _ = train_test_split(
            df, train_size=cfg.sample_rows, stratify=df[TARGET], random_state=cfg.seed
        )
    train, test = train_test_split(
        df, test_size=cfg.test_size, stratify=df[TARGET], random_state=cfg.seed
    )
    return _tidy(train), _tidy(test)


def _tidy(df: pd.DataFrame) -> pd.DataFrame:
    return df.sort_values("ID").reset_index(drop=True)


def split_path(name: str, cfg: Config) -> Path:
    return cfg.paths.processed_dir / f"{name}.parquet"


def save_splits(train: pd.DataFrame, test: pd.DataFrame, cfg: Config) -> None:
    cfg.paths.processed_dir.mkdir(parents=True, exist_ok=True)
    train.to_parquet(split_path("train", cfg), index=False)
    test.to_parquet(split_path("test", cfg), index=False)


def load_split(name: str, cfg: Config | None = None) -> pd.DataFrame:
    """Load the train or test split. With no cfg, uses this project's configs/base.yaml."""
    if name not in SPLITS:
        raise ValueError(f"name must be one of {SPLITS}, got {name!r}")
    cfg = cfg or load_config(default_config_path())
    path = split_path(name, cfg)
    if not path.is_file():
        raise DataFileError(f"{path} not found. Run `make split` first.")
    return pd.read_parquet(path)
```
